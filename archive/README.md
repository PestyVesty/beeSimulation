# Research archive

These folders preserve earlier stages of the simulation for research provenance.
They are not the recommended entry point and may depend on older library APIs.

- `01_greenhouse_reference/` — initial reproduction of a published greenhouse
  pollination model in continuous space.
- `02_open_polytunnel/` — transition to the open-polytunnel environment and
  resource-aware foraging.
- `03_latest_checkpoint_notes.md` — the final working notes from the original
  research period.
- `legacy_blank_environment.ipynb` — an unfinished empty-environment experiment
  extracted from the maintained visualisation notebook.
- `supporting_examples/` — small learning examples retained for provenance.

The maintained code is in `bee_simulation/`; current analysis notebooks are in
`notebooks/`.
